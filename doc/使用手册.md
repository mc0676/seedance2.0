## 1. 注册与登录

### 注册新账号

```
打开网站
    │
    ▼
点击「立即注册」
    │
    ▼
输入邮箱地址
    │
    ▼
设置密码（至少 8 位，必须同时包含字母和数字）
    │
    ▼
再次输入密码确认
    │
    ▼
点击「创建账号」──▶ 注册成功，自动进入主页 ✅
```

> **密码规则**：不少于 8 位，必须同时包含字母和数字。例如：`abc12345` ✅

### 登录已有账号

```
输入邮箱 + 密码 ──▶ 点击「登录」──▶ 进入主页
```

## 2. 生成第一个视频

注册登录后，系统会为你自动创建一个默认工作组，可以直接开始生成。

入口：左侧菜单 → **视频生成**

```
┌─────────────────────────────────────────┐
│              视频生成页面                 │
│                                         │
│  左侧：配置区域        右侧：预览区域      │
│  ┌──────────────┐    ┌──────────────┐   │
│  │ ① 上传素材   │    │              │   │
│  │ ② 填写提示词 │    │  生成结果在  │   │
│  │ ③ 选择模型   │    │  这里显示   │   │
│  │ ④ 选择参数   │    │              │   │
│  │ ⑤ 点击生成   │    └──────────────┘   │
│  └──────────────┘                       │
└─────────────────────────────────────────┘
```

### ① 上传参考素材（可选）

```
点击上传区域，或直接拖拽文件到页面任意位置
    │
    支持格式：
    ├── 图片：JPG、PNG、WebP（最多 9 张）
    ├── 视频：MP4、MOV（最多 1 个）
    └── 音频：MP3、WAV、M4A（最多 1 个）
    │
    ▼
素材出现在预览格中，自动编号为 @素材1、@素材2… ✅
```

> **纯文字生成**：不上传任何素材也可以，直接填写提示词即可。

---

### ② 填写提示词

在提示词框中用自然语言描述想要的视频画面，最多 5000 字符。

**写法示例：**

| 场景 | 提示词示例 |
|---|---|
| 纯文字生成 | 夕阳西下，金色光芒洒在平静的湖面上，云彩缓慢流动 |
| 引用上传的图片 | @素材1 站在咖啡馆门口，微笑着向镜头挥手 |
| 产品展示 | @素材1 旋转展示，背景是高端简约的白色空间，柔和灯光 |
| 引用素材组角色 | @素材1 缓缓走向镜头，背景是樱花飘落的公园 |

> 在提示词框内输入 `@` 符号会弹出素材选择菜单，可快速插入本次上传的图片或素材组中保存的角色。

---

### ③ 选择参考模式

| 模式 | 说明 |
|---|---|
| 全能参考 | 0–9 张图片任意组合，无图则纯文字生成 |
| 首尾帧 | 指定首图和尾图，生成首尾帧过渡视频 |

---

### ④ 选择模型

| 模型名称 | 适合场景 | 积分消耗 |
|---|---|---|
| Seedance 2.0 | 日常创作，质量均衡，支持 480p/720p | 普通 |
| Seedance 2.0 Fast | 快速出片，简短内容，支持 480p/720p | 较少 |

---

### ⑤ 选择画面参数

```
画面比例
    16:9  横屏（适合视频号、B站）
    9:16  竖屏（适合抖音、快手）
    1:1   正方形（适合小红书）
    4:3 / 3:4 / 21:9  特殊场景

分辨率
    480p  文件较小，生成较快
    720p  更清晰

视频时长
    4秒 / 5秒 / 8秒 / 10秒 / 15秒
```

---

### ⑥ 点击生成

```
查看底部积分提示
    ├── 余额充足 ──▶ 点击「生成视频」按钮（紫色）
    │
    └── 余额不足 ──▶ 按钮变为橙色警告
                     联系管理员充值积分后重试
    │
    ▼
等待生成（通常需要 30秒 - 3分钟）
右侧面板实时显示进度
    │
    ▼
生成完成 ──▶ 视频自动在右侧播放 ✅
```

## 3. 工作组：分类管理你的创作

**工作组**相当于"项目文件夹"，用来区分不同的创作主题，不同工作组之间的素材、历史记录和成员互不干扰。

```
示例场景：
┌─────────────────────────────────────┐
│  工作组A：品牌宣传片                  │
│    └── 上传品牌 LOGO、产品图           │
│    └── 历史记录：产品展示视频 20 条    │
├─────────────────────────────────────┤
│  工作组B：短剧人物                    │
│    └── 上传人物角色图                 │
│    └── 历史记录：人物对话视频 35 条    │
└─────────────────────────────────────┘
```

### 新建工作组

```
点击页面左上角的工作组名称（下拉菜单）
    │
    ▼
点击「+ 新建工作组」
    │
    ▼
输入工作组名称（如「品牌宣传」）
    │
    ▼
点击确认 ──▶ 自动切换到新工作组 ✅
```

### 切换工作组

```
点击左上角工作组下拉菜单
    │
    ▼
选择目标工作组 ──▶ 页面素材和历史记录立即切换 ✅
```

### 删除工作组

点击工作组下拉菜单中，工作组名称右侧的删除图标。

> ⚠️ 删除工作组会同时删除该工作组下的所有任务和素材绑定关系，操作不可撤销。

## 4. 素材组：管理复用角色图片

素材组用于保存固定的人物角色或常用图片，保存后可在任意视频的提示词中通过 `@素材N` 引用，无需每次重新上传。

入口：左侧菜单 → **素材组管理**

> 素材组通过火山方舟 ARK 平台管理，上传后素材需经过平台审核（通常数分钟内完成）。每个工作组可以创建多个素材组。

### 创建素材组

```
点击左侧菜单「素材组管理」
    │
    ▼
点击「+ 新建人物组合」
    │
    ▼
填写组合名称（如「品牌代言人」）
    │
    ▼
选择一张封面图片（作为组合的代表图）
    │
    ▼
点击「创建」
    ├── 正在上传图片到 OSS...
    ├── 正在创建素材组...
    └── 完成 ✅
```

### 向素材组添加素材

```
点击素材组卡片，进入素材组内部
    │
    ▼
点击右上角「+ 添加素材」
    │
    ▼
选择本地文件（图片/视频）
    │
    可填写素材名称（不填则使用文件名）
    │
    ▼
点击「上传」
    ├── 正在上传到 OSS...
    ├── 正在提交素材...
    └── 素材出现在列表中，状态显示「审核中」
    │
    ▼
等待平台审核（通常数分钟）
    │
    ▼
状态变为「已过审」──▶ 可在提示词中引用 ✅
```

> **提示**：若素材一直显示「审核中」，可点击「同步审核状态」按钮手动刷新状态。

### 在提示词中引用素材组角色

```
在视频生成页的提示词框内
    │
    ▼
输入 @ 符号
    │
    ▼
弹出素材选择菜单
    ├── 上方：本次上传的临时图片
    └── 下方：素材组中的已审核角色
    │
    ▼
点击目标素材 ──▶ 自动插入 @素材N 到提示词 ✅
```

### 管理素材组中的素材

| 操作 | 说明 |
|---|---|
| 复制 URI | 点击素材卡片上的复制图标，获取 `asset://` 格式 URI |
| 编辑名称 | 点击编辑图标修改素材显示名称 |
| 删除素材 | 点击删除图标，从 ARK 平台永久删除（不可恢复） |

## 5. 工作组成员管理

工作组支持多人协作，可邀请其他已注册用户加入，共同使用该工作组的素材和历史记录。

入口：左侧菜单 → **素材组管理** → 顶部「成员管理」标签

### 邀请成员

```
点击「成员管理」标签
    │
    ▼
在邀请框中输入对方的注册邮箱
    │
    ▼
点击「邀请」
    │
    ▼
对方出现在成员列表中 ✅
    │
    对方登录后即可在工作组下拉菜单中看到该工作组
```

> **注意**：被邀请的用户必须已经在本平台注册了账号，否则邀请会提示失败。

### 查看成员列表

成员列表中显示：
- **所有者（owner）**：工作组创建者，显示紫色标签
- **管理员（admin）**：可管理成员，显示蓝色标签
- **成员（member）**：普通协作者，显示灰色标签

### 移除成员

```
在成员列表中找到目标成员
    │
    ▼
点击该行右侧的「移除」按钮
    │
    ▼
确认弹窗 ──▶ 成员被移除，不再能访问该工作组 ✅
```

## 6. 下载视频

### 方式一：直接下载到电脑（推荐）

```
视频生成完成后，右侧播放区域显示视频
    │
    ▼
点击视频下方的「下载」按钮
    │
    ▼
浏览器自动下载 MP4 文件到本地 ✅
```

### 方式二：通过下载管理批量下载

```
点击左侧菜单「下载管理」
    │
    ▼
在列表中找到目标视频任务
    │
    ├── 单个下载：点击该行右侧「浏览器下载」按钮
    │
    └── 批量下载：勾选多条记录 ──▶ 点击「批量下载到服务器」
                  服务器下载完成后再点「浏览器下载」保存到本地
    │
    ▼

```

## 7. 积分说明

### 积分是什么？

积分是本平台的使用额度，每次生成视频会根据模型、时长、分辨率等参数消耗对应积分。

### 积分预估

生成页面底部会实时显示本次预计消耗积分和当前可用余额。

```
积分消耗示意：
┌────────────────────────────────────────┐
│ 生成一条 5 秒视频                        │
│   模型：Seedance 2.0                    │
│   含视频输入 / 720p 以下                │
│   预计消耗：约 X 积分                   │
│                                        │
│ 当前余额：100 积分                      │
│ 锁定中：0 积分                         │
│ 可用：100 积分  ✅ 可以生成             │
└────────────────────────────────────────┘
```

### 积分锁定机制

```
提交生成请求
    │
    ▼
系统预先锁定本次预估积分（余额减少，但未实际扣除）
    │
    ▼
生成进行中...
    │
    ▼
    ├── 生成成功 ──▶ 按实际消耗结算，释放多锁定的积分
    └── 生成失败 ──▶ 全额退还，不扣任何积分
```

> **注意**：若同时有多个任务在生成中，锁定积分会叠加。当可用积分不足时，按钮会变成橙色警告，等待当前任务完成后积分自动释放即可。

### 如何获取积分？

| 途径 | 操作 |
|---|---|
| 每日签到 | 登录后在签到页每天领取 |
| 激活码兑换 | 左侧菜单 → 设置 → 输入管理员提供的激活码 |
| 联系管理员 | 管理员可在后台直接为账号充值积分 |

## 8. 常见问题

**Q：注册时提示「该邮箱已被注册」？**

该邮箱已有账号，直接点击「立即登录」用该邮箱登录即可。如忘记密码，联系管理员重置。

---

**Q：按钮变为橙色，无法生成？**

当前可用积分（余额 - 锁定中）不足以覆盖本次预估消耗。等待其他任务完成积分自动释放，或联系管理员充值。

---

**Q：上传图片后提示「格式不支持」？**

仅支持 JPG、PNG、WebP 格式。截图请保存为 PNG 后重新上传。

---

**Q：提示词写了很多，但视频效果不理想？**

- 描述更加具体（包含光线、角度、动作细节）
- 减少提示词长度，保留最核心的描述
- 尝试换用不同模型

---

**Q：生成结果中人物脸部变形或不像参考图？**

- 确保参考图中人脸清晰、占比较大
- 使用素材组中经过平台审核的素材效果更稳定
- 适当降低提示词中对动作幅度的要求

---

**Q：素材组中素材一直显示「审核中」？**

审核由 ARK 平台处理，通常数分钟内完成。点击「同步审核状态」按钮手动刷新。若长时间未通过，可能是图片内容不符合平台要求。

---

**Q：视频生成了很久还没有结果？**

平台高峰期排队可能需要等待较长时间。若超过 5 分钟仍无结果，可刷新页面查看历史记录是否已有结果，或重新提交。

---

**Q：历史记录中某条任务一直显示「生成中」？**

可能是后端轮询超时。刷新页面若仍不更新，可在「下载管理」页点击「从即梦同步」补全状态。

---

**Q：邀请成员时提示失败？**

被邀请的用户必须已在本平台注册账号，且邮箱拼写正确。

---

**Q：切换工作组后素材没有更新？**

点击标题栏的刷新图标（⟳）手动重载当前工作组的素材数据。

---

**Q：我创作的视频只有自己能看到吗？**

是的，每个账号的工作组、素材和历史记录完全隔离，其他用户无法看到你的内容。工作组内的成员可以共享该工作组的素材和历史记录。

---

**Q：忘记密码怎么办？**

目前需要联系管理员重置密码。管理员重置后会告知新密码，登录后请立即到设置页修改为自己的密码。
