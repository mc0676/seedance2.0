# 🎬 Seedance 2.0 项目概括

> 企业级 AI 多媒体生成 SaaS 平台

---

## 一、技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| **前端** | React 19 + TypeScript + Vite + TailwindCSS | 构建工具含 `/api` → `:3001` 代理 |
| **后端** | Node.js 22 + Express | Alpine 容器运行 |
| **数据库** | SQLite（`better-sqlite3`，WAL 模式） | 26 张表 + 触发器自动聚合 |

| **部署** | Docker 多阶段构建 + docker-compose | 4 阶段构建，tini 进程管理 |
| **测试** | Playwright E2E | |

## 二、核心功能

### 🎬 四大 AI 生成功能

| 功能 | 页面路由 | 底层 API |
|---|---|---|
| 视频生成（Seedance） | `/` | 火山方舟 ARK API （`ark.cn-beijing.volces.com`） |
| 视频生成（HappyHorse） | `/happyhorse` | 阿里云 DashScope（`dashscope.aliyuncs.com`） |
| 图片生成 | `/image-gen` | 吴音 API |
| 音频生成 | `/audio-gen` | ARK 生成静默视频 → 浏览器端 lamejs 转 MP3 |
| 画质增强 | `/enhancement` | 火山 AI MediaKit（`mediakit.cn-beijing.volces.com`） |

### 💳 积分计费体系
- 生成前通过 `creditLockService` **锁定预估积分**（防超扣）
- 完成后按实际时长 / 分辨率 / FPS **精算结算**，释放差额
- 支持折扣（百分比 / 绝对值两种方式）
- 管理员可设置发分额度上限

### 🔐 用户权限系统
- 三级角色：`user` / `admin` / `super_admin`
- Session 认证，凭证存 `localStorage`，请求头 `X-Session-ID`
- 支持**密码登录** + **邮箱验证码登录**（nodemailer + SMTP）
- 全局**维护模式**锁定，admin 可绕过

### 📦 素材库
- 本地上传 → 阿里云 OSS 存储 → 同步到火山 ARK 素材组
- `auto_inject` 开关：自动将素材注入生成请求

## 七、核心数据流

```
用户提交视频生成请求
    │
    ▼
POST /api/tasks（server/index.js）
    │  权限检查（authenticate middleware）
    │  积分锁定（creditLockService.lock）
    ▼
videoGenerator.js → ARK API（火山方舟）
    │  返回 taskId，写入 DB（status=pending）
    ▼
Worker 后台定时轮询（node-cron）
    │  定时查询任务状态
    │  done → 写入 video_url，更新 status=done
    ▼
creditLockService.settle（精算实际积分消耗）
    │
    ▼
前端轮询 GET /api/tasks/:id
    │  获取最新状态和视频 URL
    ▼
下载链路：POST /file-token → GET /file-by-token?token=xxx
```

## 八、Docker 部署架构

```
Dockerfile 4 阶段构建：
  Stage 1: deps-frontend      → npm ci 安装前端依赖
  Stage 2: frontend-build     → tsc + vite build → dist/
  Stage 3: deps-server        → npm ci --production（含 python3/make/g++ 编译 better-sqlite3）
  Stage 4: production         → Node 22 Alpine + tini，EXPOSE 3001
                                 VOLUME /app/server/data（DB 持久化）
                                 VOLUME /app/dist（前端产物）
```

| 配置文件 | 用途 |
|---|---|
| `docker-compose.yml` | 生产，端口 3001，挂载 `./data` 和 `./dist` |
| `docker-compose-dev.yml` | 开发，热重载 `--watch`，额外暴露 5173 端口 |
